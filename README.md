# Super CMD Toolkit
A Windows batch file toolkit for IT troubleshooting and system diagnostics.

## Features
- Networking: ipconfig, ping, tracert, netstat
- System: systeminfo, tasklist, driverquery, winget upgrade
- Storage & Security: sfc, DISM, chkdsk, printer spooler reset
- Utilities: regedit, services, event viewer
- Power: shutdown, restart, logoff
- Extras: control panel, device manager, firewall

## Usage
1. Download `Toolkit.bat`.
2. Right‑click → Run as Administrator.
3. Select an option from the menu.
